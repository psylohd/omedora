# Nokron Plymouth Theme

A Plymouth boot splash replicating Omarchy's ASCII-block wordmark style,
with a Fedora-blue background and the letters **FEDORA** centered.

## Wordmark source

The **FEDORA** wordmark is generated by `omarchy-ascii.sh` — Omarchy's port of
the Delta Corps Priest 1 figlet font. Running `./scripts/render-wordmark.py`
re-runs the script and rasterizes the output to PNGs using only the Python
standard library.

To change the wordmark text, edit `logos/fedora.txt` directly and re-run the
renderer, or pass a new text:

```bash
python3 scripts/render-wordmark.py Omarchy
```

The renderer reads unicode block characters (█ ▀ ▄ ▌ ▐) and rasterizes them
to an 8×8 pixel cell. The output PNG is 800×135 px with a transparent
background.

## Install

```bash
cd ~/dev/nokron-plymouth
./install.sh   # installs to /usr/share/plymouth/themes/nokron, rebuilds initramfs
```

The installer:
1. Copies theme files to `/usr/share/plymouth/themes/nokron/`
2. Sets `nokron` as the default Plymouth theme
3. Rebuilds the initramfs with `dracut`

Reboot to see it.

## Files

- `nokron.plymouth` — Plymouth theme metadata
- `nokron.script` — Plymouth script-module animation logic
- `logo.png` — 800×183 ASCII wordmark PNG (transparent background)
- `lock.png`, `entry.png`, `bullet.png`, `progress_bar.png`, `progress_box.png` — UI elements reused from Omarchy
- `logos/fedora.txt` — the 7-row ASCII source for the wordmark
- `logos/fedora.png` — same wordmark at native resolution before scaling
- `plymouthd.conf` — overrides `/etc/plymouth/plymouthd.conf` to point at this theme
- `install.sh` / `uninstall.sh` — installers

## Re-generating the wordmark

`logos/fedora.txt` is the source of truth for the wordmark. To regenerate:
```bash
python3 scripts/render-wordmark.py
```

Or edit the ASCII art in `logos/fedora.txt` directly and re-render.

## Background

Inspired by Omarchy's boot splash (`~/dev/omarchy/default/plymouth/`).
Same script-module structure, same dialogue/progress bar behavior,
just a Fedora-flavored wordmark and color palette.

## Uninstall

```bash
./uninstall.sh
```

Restores the `charge` theme (or `spinner`/`text` as fallback) and rebuilds initramfs.
